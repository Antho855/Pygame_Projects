## 🕹️ Game Description

Inspired by the classic Pong, with exciting twists:

The ball gradually increases its speed during gameplay.

Random bonuses make each match dynamic:

- Bigger or smaller paddles
- Faster or slower ball
- Extra life

This makes the game challenging and fun, even for experienced players.

## 🛠️ Concepts Learned

This project helped me practice:

- Object-Oriented Programming – creating classes for players, ball, and bonuses.
- Collision detection – detecting interactions between the ball, paddles, and bonuses.
- Timers & temporary effects – handling bonuses without freezing the game.
- Game loop management – controlling frame updates for smooth gameplay.
- Pygame basics – creating surfaces, drawing shapes, and managing input.

## ⚡ Installation & Play

Clone this repository:

```
git clone https://github.com/Antho855/Pygame_Projects.git
cd the-pong-v2
```

Install dependencies:

```
pip install pygame
```

Run the game:

```
python main.py
```
