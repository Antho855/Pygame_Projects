## 🕹️ Game Description  

Inspired by the legendary **Snake** game, this modern version brings a touch of nostalgia with a clean retro design and smooth gameplay.  

Your goal is simple:  
➡️ Move the snake across the grid  
🍎 Eat food to grow longer  
💥 Avoid hitting the walls or yourself  

Features include:  
- A start screen with a “Press SPACE to Start” intro  
- Gradual speed increase for more challenge  
- Dynamic grid and score display  
- Automatic reset after each game over  

---

## 🛠️ Concepts Learned  

This project helped me practice and understand key game development principles in **Pygame**:  

- **Object-Oriented Programming (OOP)** – creating modular classes for `Snake`, `Food`, and `Game`  
- **Event handling** – managing keyboard inputs and custom update timers  
- **Collision detection** – between snake and food, or with borders  
- **Game state management** – intro screen, running mode, game over, reset  
- **Frame rate control** – ensuring consistent game speed and smooth animation

## ⚡ Installation & Play  

**1. Clone this repository:**  
```bash
git clone https://github.com/Antho855/retro-snake.git
cd retro-snake
```

Install dependencies:

```
pip install pygame
```

Run the game:

```
python main.py
```
