# 1. Pygame : Square catch

Hi! I’m a French developer, and I would like to create video games.
As a first step, I decided to start with Pygame in Python.

This is the first game of a series that will help me learn game development with Pygame.

## 🎮 Description of the game

The goal of this game is simple:

- You only have 3 lives.
- Catch the green objects to get points (+5)
- If an object reaches the bottom of the screen, you lose 2 points and 1 life.

The game ends when you run out of lives.

## 🛠️ Concepts Learned

- Key inputs: Arrow keys for movement, SPACE to start, R to restart.
- Collision detection between the player and falling objects.
- Timers to manage frame updates and spawning new objects.
- Game states (intro, active, game over) to display different screens.
